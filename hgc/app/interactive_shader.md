a small webapp that can be used to create .gif's and videos from rendered shaders. 

the shaders consists of two parts: 
- sdf function templates, the user can pick from 
- visualization templates, the user can pick from

after picking a template it is shown in a monaco editor
when the template is edited the changes show in realtime 
a new tample based on the old template can be saved to the server

default shader resolution is 2048x2048

default shader is a simple circular sdf
